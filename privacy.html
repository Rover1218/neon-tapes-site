Privacy Policy

Last updated: 26 September 2026

1. Who this covers

“Neon Tapes” (the “App”) is a personal, automated tool that creates original music and publishes it to a single YouTube channel owned by the operator of this App. The App is not offered as a service to other people, has no sign-up, and has no users other than its owner.

2. What the App accesses

When the owner signs in with Google, the App requests permission to:

  • Upload videos to the owner’s own YouTube channel.
  • Set the thumbnail image on the videos it has uploaded.

The App uses these permissions only to publish the music it generates. It does not read, modify or delete any other video, playlist, comment, subscriber list or channel setting.

3. What data is stored, and where

The App stores an OAuth refresh token issued by Google. This token lets the App upload on the owner’s behalf without signing in each week. It is stored as an environment value on a private server controlled by the owner, readable only by the owner’s account on that server.

The App also stores, in a plain text file on that same server, a record of each song it has published: the date, the musical theme, the song title, the genre, and the resulting YouTube video ID. This exists so the App does not repeat a title it has already released.

No other personal data is collected, stored or processed. The App has no database of people, no analytics, no advertising, no cookies and no tracking of any kind. It does not collect information about anyone who watches the videos it publishes; viewer data is handled entirely by YouTube under Google’s own privacy policy.

4. Data sharing

Data is never sold, rented, traded or shared with third parties. The only parties involved are:

  • Google / YouTube, which receives the uploaded video and its description in order to publish it.
  • Google Gemini, which receives the App’s text prompts in order to write song lyrics.
  • Hugging Face, which receives the App’s text prompts in order to generate cover artwork.

None of these receive personal data about the owner or about viewers beyond what is inherent in making the request.

5. Google API Services User Data Policy

The App’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically, data obtained through Google APIs is used only to provide the App’s single function — publishing the owner’s own music to the owner’s own channel — is not transferred to others except as required to provide that function, is not used for advertising, and is not read by humans except where required for security purposes or to comply with applicable law.

6. Retention and deletion

The OAuth token is kept only while the App is in use. The owner can revoke the App’s access at any time at myaccount.google.com/permissions.

Revoking access immediately and permanently ends the App’s ability to reach the YouTube account. The stored token then stops working and can be deleted by removing it from the server’s environment file. The record of published song titles contains no personal data and can be deleted at any time by deleting that file.

7. Children

The App is not directed at children and collects no data from anyone, including children.

8. Security

The refresh token is kept in a file readable only by the owner’s account on a private server. API keys and tokens are filtered out of the App’s log files before they are written, so that logs can be reviewed or shared without exposing credentials.

9. Changes to this policy

If the App’s behaviour changes in a way that affects this policy, this page will be updated and the “Last updated” date above will change.

10. Contact

Questions about this policy can be sent to the support email address shown on the Google consent screen for this application.
